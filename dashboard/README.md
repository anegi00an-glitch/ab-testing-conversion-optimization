# Experiment dashboard specification

## Experiment overview

**KPI cards:** Control conversion · Treatment conversion · Absolute lift · Relative lift · p-value

**Primary visual:** Control vs treatment conversion-rate comparison

**Statistical panel:** Two-proportion z-test result and decision threshold

**Exploratory cuts:** Conversion by country, device, and channel with minimum-volume safeguards

**Decision rule:** Treat p < 0.05 as statistically significant for the primary comparison; segment cuts are exploratory.

The experiment is simulated for portfolio purposes. It demonstrates an experimentation workflow and does not claim to represent a real company's test.
