# Visuals

These charts are generated directly from the simulated experiment dataset committed in this repository.

- `ab_conversion_rate.svg` — control vs treatment conversion rate
- `ab_channel_conversion.svg` — conversion by acquisition channel (generated locally during portfolio build)
- `ab_device_conversion.svg` — conversion by device (generated locally during portfolio build)

The experiment is simulated for portfolio purposes; these charts must not be presented as evidence from a real company experiment.
