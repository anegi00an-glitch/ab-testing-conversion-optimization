# Dataset source

**Reference dataset:** Conversion Rate dataset

**Public source reference:** https://github.com/jainds/eda-for-conversion-rate-dataset

This portfolio repository uses a simulated experiment dataset generated for the project workflow rather than claiming that the public source contains a real treatment/control experiment. The source link is provided for provenance of the underlying conversion-data structure; the experiment design, statistical analysis, and interpretation are independent portfolio work.
